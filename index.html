🖼️ 이미지 가져오기

Pixabay에서 사진을 검색하거나, 이미지 주소를 붙여 넣어 화면에 출력해 보세요.

1️⃣ Pixabay API 키

🔒 키는 이 브라우저에만 저장되고 GitHub에는 올라가지 않아요. 코드 파일에 직접 적지 마세요. 저장소가 공개라면 다른 사람이 내 키를 쓸 수 있어요.

2️⃣ 사진 검색

API 키를 저장한 뒤 검색해 보세요.

사진 제공: Pixabay

3️⃣ 이미지 주소로 불러오기

이미지를 오른쪽 클릭 → "이미지 주소 복사"로 복사한 주소를 넣으세요. (웹페이지 주소 pixabay.com/photos/…가 아니라 cdn.pixabay.com/…jpg 같은 이미지 파일 주소예요.)
